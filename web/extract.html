How to record

  1. Open a Pokémon in storage and tap Appraise so the Willow panel stays open.
  2. Swipe through storage, pausing about a second on each Pokémon.
  3. Stop the recording and drop the file above.

The first run downloads the OCR language file (about 4 MB), then everything happens on this device. Already have a Poke Genie export instead? Use the CSV importer.
