Notes for the build (turn 6 state)
Structure. Base screen (5a): the LEAGUES panel holds one pick card per league. Tapping a card pushes the league view (5c) inside the same panel: back circle, league control, pick card, "Show more" / "Show less", option rows that expand inline. The Normal / Mega form switch is the model for the control.
Copy. League lines: "Under 1,500 CP", "Under 2,500 CP", "No CP cap". Chip: "PICK", or "POGO ASSIST PICK" when that scoring is on. Figure labels: "Species", "This copy", "Dust" (list header: "Option"). Cost list: "Target level: 18.5", "Target CP: 1,500", "6,600 dust", "31 candy" (candy is one total; XL appended as ", 296 XL"). Unranked: species figure blank. IVs not read: "—" / "not read", dust "—" / "no cost". Level unknown: dust "—" / "level not known"; card note "Level not known, so no cost". Over cap: card "Already above 1,500 CP, so it cannot be used in Great League as any of the family."; row "Over 1,500 CP as Corviknight"; best-available note "Corviknight is the stronger species, but this copy is already over 1,500 CP as Corviknight." Past its level: "Past its best Ultra League level; 100 candy". At its level: "Already at level 51; 100 candy". Gender lock: "Gallade, if it is male". Move chips: move names; "Needs Overheat" in orange. Footnote: "Pogo Assist is currently unable to detect Shadow Pokémon." Scoring explainer: the three paragraphs in 5b.
Accessibility identifiers. Kept: leagues-panel, league-gl / league-ul / league-ml. New: leagues-scoring (the switch), leagues-scoring-info, leagues-control (the league tabs), leagues-back, league-gl-pick (the card), league-gl-more (Show more), league-gl-option-Umbreon (each row, by species id in the build).
VoiceOver order. Base screen: "Leagues" header → scoring switch (adjustable, "Default" / "Pogo Assist") → info button → three cards, each one button: "Great League, under 1,500 CP. Pick: Flareon. Species 68.9, rank 710 of 1,152. This copy 97.2 percent, IV rank 216. Target level 18.5, target CP 1,500, 6,600 dust, 31 candy. Moves Ember, Overheat, Flamethrower. Button." → footnote. League view: back button "All leagues" → header → switch → tabs ("Great, selected, tab 1 of 3") → pick card (one element, not a button) → "Show more, button, collapsed" → each row as one button: "Umbreon. Level 26.5, CP 1,481. Species 90.2, rank 24. This copy 94.8 percent, IV rank 1,879. 57k dust, 75 candy. Collapsed." → expanded detail as plain text under it.
