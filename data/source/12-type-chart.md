# Type chart

The Pokémon GO type chart: a super effective attack does 1.6 times the damage, a not very effective one 0.625 times, and an attack on a type that is immune in the main games does 0.390625 times (two not-very-effective steps). Rows are the attacking type, columns the defending type; against a Pokémon with two types, multiply the two cells. Edit this file, then run `npm run build:hub`.
