## The morning test needs no laptop

`docs/morning-test.md` is a browser test of the live page. Run it from the iPhone itself (Safari,
pick the recording from Photos) or the iPad; those decode HEVC natively. The laptop is only needed
for the Windows Chrome check and for the CLI.

## Setting the laptop up for the CLI

```bash
git clone https://github.com/dare33/pogo-assist-plus.git
cd pogo-assist-plus
npm install
npm test
```

Node 20 or newer (the test glob needs 21+). ffmpeg for decoding: `winget install Gyan.FFmpeg`
on Windows, `brew install ffmpeg` on a Mac, or set `FFMPEG` to any ffmpeg binary. Then copy the
recordings from Drive into `recordings/` (gitignored) and run:

```bash
node scripts/extract.mjs recordings/iphone-clipchamp-trimmed.mp4 --out out/trimmed.csv
```

Expect the four acceptance rows with no flags. With the recordings in place `npm test` also runs
the integration checks against them (it skips them when they are absent).
